# 屏幕滚动字幕 / 便签工具 - 设计文档

## 1. 背景与目标

开发一个跨平台桌面小工具（优先 Windows，后续考虑 macOS/Linux），核心功能是在屏幕上显示可自定义的文字层，用途覆盖两类场景：

1. **提词器**：直播/录屏时滚动显示讲稿、台词
2. **桌面便签**：常驻屏幕显示提醒文字，固定不滚动

软件要求：界面简洁好看、体积小、支持创建多个文字面板（便签功能）。

## 2. 技术方案

- **框架**：Tauri 2.x（Rust 后端 + WebView 前端）
  - 预计打包体积 5-15MB，远小于 Electron 方案
  - 前端使用 React/Vue + TypeScript（具体二选一，在实现阶段确定）
- **平台优先级**：Windows 优先实现与测试，Tauri 原生支持跨平台打包，后续可扩展 macOS/Linux

## 3. 窗口模型

软件由两类窗口组成：

### 3.1 主控制面板窗口
- 普通窗口（非透明、非置顶）
- 负责管理所有文字面板：新建、编辑、删除、显示/隐藏
- 最小化到系统托盘，托盘菜单支持快速显示/隐藏主面板、退出程序

### 3.2 文字面板窗口（Overlay）
- 每个面板对应一个独立的 Tauri 窗口
- 特性：`transparent: true`、`always_on_top: true`、`decorations: false`
- 可创建任意多个，彼此独立

## 4. 交互设计

### 4.1 穿透 / 编辑模式切换
- **默认状态**：鼠标点击穿透到下方窗口（不拦截鼠标事件），文字按设定方式显示/滚动，不显示任何边框
- **悬停状态**：鼠标移动到窗口区域内（含少量 padding 热区）时，自动显示半透明边框和四角/四边拖拽手柄，此时窗口暂停穿透，可拖拽移动位置、拖拽边角调整大小
- 鼠标移出窗口区域后，边框和手柄消失，恢复穿透状态
- 实现要点：Tauri `set_ignore_cursor_events` 动态切换 + 前端监听鼠标进入/离开事件

### 4.2 编辑文字/样式
- 悬停边框出现时，显示一个小的编辑按钮（铅笔图标）
- 点击后弹出编辑弹层，可修改文字内容、滚动参数、样式设置
- 避免在 overlay 窗口内直接放置复杂表单，保持 overlay 简洁

## 5. 功能需求

### 5.1 文字内容与样式
**基础样式集**（优先实现）：
- 字体大小
- 字体颜色
- 背景颜色
- 背景透明度
- 滚动速度
- 滚动方向（水平 / 垂直 / 不滚动）

**进阶样式**（基础集完成后迭代）：
- 字体粗细 / 斜体
- 文字对齐方式
- 边框样式
- 阴影
- 自定义字体文件导入

### 5.2 滚动模式
支持两种滚动样式，用户可选：
- **水平滚动**（跑马灯）：文字从右到左横向移动
- **垂直滚动**（提词器式）：文字从下往上纵向滚动，类似电影片尾字幕

滚动可设置：速度、是否循环

### 5.3 滚动启停控制
- 控制面板中可对单个面板暂停/继续/调整速度
- 全局快捷键（如 `Ctrl+Alt+Space`）：暂停/继续所有正在滚动的面板，适合提词器场景临场操作

### 5.4 多面板管理（便签功能）
- 主控制面板中维护面板列表，每项展示：名称/文字预览
- 每项操作：显示/隐藏开关、编辑、删除
- "新建面板"按钮：创建一个默认样式的新 overlay 窗口

### 5.5 调整大小与位置
- 通过鼠标拖拽边框/四角手柄调整整个矩形的大小
- 通过拖拽窗口内部（悬停状态下）调整位置
- 支持多显示器环境，面板位置使用绝对屏幕坐标，可跨屏拖拽

## 6. 数据持久化

- 软件关闭后自动保存所有面板配置，下次打开自动恢复（文字、位置、大小、样式、滚动参数、显示状态）
- 存储位置：本地 JSON 文件（如 `%APPDATA%/pinmu-gundong/panels.json`）
- 读写通过 Tauri 文件系统 API 实现

### 6.1 单个面板数据结构示例

```json
{
  "id": "uuid",
  "name": "台词1",
  "text": "这里是滚动或固定的文字内容",
  "position": { "x": 100, "y": 100 },
  "size": { "width": 400, "height": 120 },
  "style": {
    "fontSize": 24,
    "fontColor": "#ffffff",
    "fontWeight": "normal",
    "fontStyle": "normal",
    "bgColor": "#000000",
    "bgOpacity": 0.5,
    "textAlign": "left"
  },
  "scroll": {
    "mode": "none | horizontal | vertical",
    "speed": 50,
    "loop": true
  },
  "visible": true
}
```

## 7. 错误处理

- 配置文件损坏/缺失：启动时捕获异常，回退到空列表并提示 toast 通知
- 窗口被意外关闭（如 Alt+F4）：捕获关闭事件，更新配置中对应面板 `visible: false`，而非直接删除数据，保证数据不丢失
- 多显示器下面板位置失效（如外接屏被拔出）：检测坐标是否超出可见屏幕范围，超出则自动拉回主屏幕可见区域

## 8. 测试策略

- 前端逻辑（样式计算、滚动动画参数）：使用 Vitest 做单元测试
- Rust 侧（文件读写、窗口管理命令）：使用 Rust 自带测试框架
- 手动测试清单需覆盖：
  - 创建/删除面板
  - 拖拽调整大小/位置
  - 穿透/悬停模式切换
  - 重启应用后配置正确恢复
  - 全局快捷键暂停/继续滚动
  - 多显示器环境下面板行为

## 9. 开发阶段规划（MVP 分阶段实现）

建议按以下顺序分阶段实现，每个阶段产出可验证的最小成果：

1. **阶段1 - 项目骨架**
   - Tauri + 前端框架初始化
   - 跑通一个基础的透明置顶窗口（无交互）

2. **阶段2 - 单面板核心功能**
   - 文字显示
   - 基础样式设置（字体/颜色/背景/透明度）
   - 拖拽调整大小和位置
   - 穿透/悬停模式切换

3. **阶段3 - 滚动功能**
   - 水平滚动（跑马灯）实现
   - 垂直滚动（提词器式）实现
   - 滚动速度控制、暂停/继续

4. **阶段4 - 多面板管理**
   - 主控制面板 UI
   - 面板增删改查
   - 系统托盘图标与菜单

5. **阶段5 - 持久化**
   - 配置自动保存/恢复
   - 异常处理（配置损坏、窗口意外关闭等）

6. **阶段6 - 打磨与发布**
   - 全局快捷键（暂停/继续所有滚动）
   - 进阶样式（粗体/斜体/对齐/阴影/自定义字体）
   - UI 美化
   - 打包测试（Windows 优先，再评估 Mac/Linux 支持）

## 10. 待决事项（后续实现阶段确定）
